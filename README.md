# PublikAI Studio UI/UX Prototype

UI/UX prototype untuk platform **AI Public Content Studio** — fokus MVP pada kategori **AI Social Media**.

## Konsep

User memilih format konten, isi brief singkat, lalu AI menjalankan workflow yang sudah ter-framework:

1. Brief
2. Strategy
3. Copywriting
4. Visual Prompt
5. Generate Asset
6. Export

## Screen yang ada

- Landing hero
- Content type cards: Single Feed, Carousel, Reels
- Workflow rail
- Brand profile panel
- Carousel generator mockup
- Output asset cards

## Tech Stack

- Vite
- React
- TypeScript
- Custom CSS

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
